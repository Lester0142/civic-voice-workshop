# Contributing to the workshop

Participant workflow, branch naming, draft PR requirements, and the fixed PR template live in [docs/workshop/participant-workflow.md](docs/workshop/participant-workflow.md).

The short version:

- one ticket per branch;
- open a draft PR as soon as work starts;
- use `CV-###: <exact ticket title>` as the PR title;
- run `npm test` and `npm run build` before requesting scoring.
